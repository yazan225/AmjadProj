مقدمة وشروحات أساسية

مرحباً بك في الدليل الشامل لنظام MacPro Accounting، ستتعلم في هذا الدليل كل ما تحتاجه لتشغيل النظام بكفاءة

عن النظام

MacPro Accountingهو نظام مفتوح المصدر لإدارة المحاسبة والمخازن والمبيعات، مصمم خصيصاً للشركات الصغيرة والمتوسطة.

  • 1
    يدعم إدارة متعددة الشركات
  • 2
    واجهة مستخدم عربية كاملة
  • 3
    تقارير متقدمة وتحليلات

خطة التعلم

اتبع هذه الخطوات بالترتيب لإتقان النظام:

  • إعداد الشركة والمستخدمين
  • تهيئة المخازن والمواقع
  • إضافة العملاء والموردين
  • تسجيل الأصناف والمنتجات
  • تعلم عمليات البيع والشراء
  • تحليل التقارير والمؤشرات

إعداد الشركة

تعلم كيفية إنشاء وإعداد الشركة في النظام مع كل الإعدادات الأساسية

إنشاء شركة جديدة

لإنشاء شركة جديدة في النظام:

  • 1
    ادخل كمسؤول للنظام
  • 2
    اذهب إلى الإدارة → إعداد الشركات
  • 3
    انقر على إنشاء شركة جديدة
  • 4
    املأ البيانات الأساسية
  • 5
    حدد البادئة الرقمية (مثل 2_)

الإعدادات الأساسية

البيانات المطلوبة لإنشاء الشركة:

  • اسم الشركة الكامل (بالعربية والإنجليزية)
  • العنوان التفصيلي والموقع
  • أرقام الهواتف والبريد الإلكتروني
  • العملة الأساسية (مثل: شيكل، دولار)
  • بداية السنة المالية
  • نظام الضرائب المستخدم
البادئة الرقمية تحدد اسم الجداول في قاعدة البيانات
بعد إنشاء الشركة بنجاح، يمكنك البدء في إضافة المستخدمين والمخازن

إعداد المخازن

إدارة وتنظيم مواقع التخزين والمستودعات في النظام

إضافة مواقع المخازن

لإضافة موقع تخزين جديد:

  • 1
    اذهب إلى المخزون → مواقع المخازن
  • 2
    انقر على إضافة موقع جديد
  • 3
    أدخل كود الموقع (مثل: MAIN, STORE)
  • 4
    اكتب اسم الموقع بالكامل
  • 5
    حدد العنوان وبيانات الاتصال

هيكل المخازن المقترح

لمنشأة متوسطة الحجم، نوصي بالمخازن التالية:

MAIN - المستودع الرئيسي
STORE - مستودع التخزين
SHOP - مستودع المبيعات
RETURN - مستودع المرتجعات
DAMAGED - مستودع التالف
TRANSIT- مستودع العبور
يمكنك تخصيص الأكواد والأسماء حسب احتياجات عملك

إعدادات المخازن المتقدمة

إعدادات إضافية مهمة للمخازن:

  • تعيين مسؤول لكل مخزن
  • تحديد سعة التخزين القصوى
  • إعداد مناطق التخزين (رفوف، أقسام)
  • ربط المخازن بفروع الشركة
  • تفعيل نظام الجرد الآلي
  • إعداد تنبيهات المخزون الأدنى
كود المخزن الاسم الوصف المسؤول
MAIN المستودع الرئيسي المخزن الرئيسي للشركة مدير المخازن
STORE مستودع التخزين لتخزين البضائع طويلة الأجل أمين المخزن
SHOP مستودع المبيعات للتجهيز للبيع المباشر منسق المبيعات

- عملاء تجزئة
- عملاء موزعين

# حسب طريقة الدفع:

بيانات العميل الأساسية

المعلومات المطلوبة لكل عميل:

  • الاسم الكامل أو التجاري
  • رقم الهوية أو السجل التجاري
  • العنوان التفصيلي
  • أرقام الهواتف والبريد الإلكتروني
  • فئة العميل
  • حد الائتمان المسموح
  • شروط الدفع المتفق عليها
  • تفضيلات الخصم
يجب إضافة عميل باسم "Walk-In Customer" لاستخدامه في المبيعات النقدية المباشرة
كود العميل الاسم الفئة حد الائتمان شروط الدفع

CUST002 محل الأماني عملاء تجزئة 10,000 ₪ نقدي
WALKIN عميل نقدي عملاء نقدي 0 ₪ نقدي
